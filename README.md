# Relatório de Alterações de Custo

## Sobre o projeto

Este projeto tem como objetivo automatizar a geração do relatório de alterações de custo dos produtos, substituindo um processo atualmente realizado de forma manual pela equipe.
A solução identifica os produtos que tiveram seus custos alterados pelo setor comercial, consolidando as informações necessárias para facilitar o acompanhamento e a análise dessas mudanças.

## Objetivos

- **Automatização:** reduzir o trabalho manual e o tempo necessário para gerar o relatório.
- **Confiabilidade:** padronizar o processamento e a consolidação dos dados.
- **Análise de dados:** disponibilizar informações estruturadas sobre as alterações de custo dos produtos.
- **Acessibilidade:** permitir que os usuários consultem e analisem os resultados de maneira prática.

## Aplicação

Os dados processados poderão ser disponibilizados em uma planilha Excel ou em uma aplicação web, permitindo que os usuários explorem as informações, realizem análises e acompanhem as alterações de custo conforme suas necessidades.

## Finalidade

Transformar um processo manual em uma solução automatizada, padronizada e escalável, contribuindo para a eficiência operacional e para a tomada de decisões na área comercial.

## Linguagens utilizadas:
Python e SQL
